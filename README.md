# 📊 Proyek Analisis Data: E-Commerce Olist

Dashboard analitik interaktif berbasis **Streamlit** untuk menganalisis performa platform E-Commerce Olist berdasarkan data publik dari Kaggle.

## ⚙️ Setup Environment

```bash
mkdir proyek_analisis_data
cd proyek_analisis_data
pipenv install
pipenv shell
pip install -r requirements.txt
```

## 🚀 Run Streamlit App

```bash
streamlit run dashboard/dashboard.py
```

## 📊 Dataset

Dataset yang digunakan adalah **Brazilian E-Commerce Public Dataset by Olist** dari Kaggle.

- Periode: September 2016 – Oktober 2018
- Dashboard memfilter: **Januari 2017 – Agustus 2018** (pesanan delivered)
